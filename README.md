# ملفات علي — المرحلة الأولى

تطبيق أندرويد (Kotlin + Jetpack Compose) فيه: **المتصفح، المحمّل، الخزنة المشفرة**.
أندرويد 10 أو أحدث (يشتغل على Galaxy A52s والـ MatePad).

## البناء على الماك (أسهل طريقة)

1. نزّل وثبّت **Android Studio** من developer.android.com/studio
2. افتح Android Studio ← **Open** ← اختار فولدر `AliFiles`
3. استنى لحد ما Gradle يخلص أول مرة (بينزّل المكتبات، أول مرة بتاخد 5–10 دقايق)
4. وصّل الموبايل بالكابل وفعّل **USB debugging** (الإعدادات ← حول الهاتف ← اضغط «رقم الإصدار» 7 مرات ← خيارات المطور ← تصحيح USB)
5. دوس ▶️ **Run** — التطبيق هيتثبت على الموبايل

لو عاوز ملف APK تبعته لأي جهاز: **Build ← Build App Bundle(s) / APK(s) ← Build APK(s)**
هتلاقيه في `app/build/outputs/apk/`.

> لو ظهر خطأ أثناء البناء: افتح Claude Code في فولدر المشروع وقوله «ابني المشروع وصلّح أي أخطاء» — أو ابعتلي رسالة الخطأ.

## البناء على GitHub (من غير Android Studio)

ارفع الفولدر على مستودع GitHub — هيتبني تلقائياً، والـ APK هيظهر في تبويب **Actions** ← آخر تشغيل ← **Artifacts**.

## المميزات

### المتصفح
- تبويبات متعددة + تبويب خاص (من غير سجل)
- مانع إعلانات وتتبع + **مانع نوافذ منبثقة ذكي** (مبيفتحش تبويب جديد غير لو انت ضغطت فعلاً)
- **لاقط الوسائط**: بيلقط أي فيديو/صوت/بث HLS في الصفحة وتحمّله بضغطة
- ضغطة مطولة على أي رابط أو صورة ← فتح / تحميل / نسخ
- المفضلة والسجل، بحث جوه الصفحة، وضع الكمبيوتر، فيديو ملء الشاشة، رفع ملفات للمواقع
- بيفتح روابط التطبيقات التانية (واتساب، المتجر…)
- اكتب IP جهاز (راوتر/انفرتر) ويفتحه على طول

### المحمّل
- **تحميل متعدد الخيوط** (لحد 16) — أسرع بكتير مع السيرفرات اللي بتدعم
- إيقاف واستكمال، حتى لو التطبيق اتقفل أو الموبايل اتعمله ريستارت
- **تحميل بث HLS (.m3u8)** بما فيه المشفر AES-128 — بيتجمع في ملف واحد
- إعادة محاولة تلقائية لو النت فصل
- بيبعت الكوكيز والهوية بتاعة المتصفح، فالتحميلات اللي محتاجة تسجيل دخول بتشتغل
- السرعة والوقت الباقي، وإشعار لما يخلص
- **شارك أي لينك للتطبيق** من أي برنامج ← يفتحه أو يحمّله
- **التقاط الروابط من الحافظة**: انسخ لينك وافتح التطبيق، هيعرض عليك
- الحفظ في `Download/AliFiles` **أو مباشرة في الخزنة**

### الخزنة
- تشفير **AES-256-GCM** لكل ملف بمفتاح خاص بيه، والمفاتيح في شريحة الأمان بتاعة الموبايل (Android Keystore)
- حتى **أسماء الملفات والصور المصغرة متشفرة**
- رمز سري (PBKDF2) + **بصمة** + قفل مؤقت بعد المحاولات الغلط
- بتتقفل أول ما تخرج من التطبيق، و**ممنوع تصوير الشاشة** جواها
- عارض صور جوه التطبيق بالزوم، وباقي الملفات تتفتح بالتطبيقات التانية
- شارك أي ملف من أي تطبيق ← يدخل الخزنة
- بعد الإضافة يعرض عليك تمسح النسخة الأصلية
- إخراج ملفات، مشاركة، إعادة تسمية، بحث وفلترة حسب النوع

## ملاحظات أمان
- ملفات الخزنة مربوطة بالموبايل ده: **لو مسحت التطبيق أو عملت فورمات، الملفات المشفرة مش هترجع**. خلي نسخة احتياطية من المهم برة (هتتضاف ميزة نسخ احتياطي مشفر في مرحلة جاية).
- لما تفتح ملف من الخزنة في تطبيق تاني، بتتعمل نسخة مؤقتة جوه كاش التطبيق وبتتمسح أول ما تفتح الخزنة تاني.
- الفيديوهات المحمية بـ DRM (نتفليكس وغيره) مينفعش تتحمل.
