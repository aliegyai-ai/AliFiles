# حمّل — مدير ملفات علي

تطبيق ويب (React + TypeScript) بيتحوّل لـ APK بـ **Capacitor**.
نسخة الـ Kotlin القديمة محفوظة في فرع `legacy-kotlin`.

## تنزيل الـ APK

كل تعديل بيتبني تلقائي على GitHub، وآخر نسخة دايمًا على اللينك ده:

https://github.com/aliegyai-ai/AliFiles/releases/download/latest/AliFiles.apk

> التطبيق الجديد اسمه «حمّل» وبيتسطّب **جنب** التطبيق القديم (ملفات علي) مش مكانه.
> لو عندك ملفات في خزنة التطبيق القديم، طلّعها الأول قبل ما تمسحه.

## الخطة — المرحلة الأولى

| الخطوة | الحالة |
|---|---|
| 1. الواجهة (الملفات، التحميلات، الخزنة، الإعدادات) | ✅ |
| 2. الخزنة المشفّرة (رمز سري + AES-256 + بصمة) | ⏳ |
| 3. متصفح الملفات الحقيقي على الموبايل | ⏳ |
| 4. المحمّل (يوتيوب / فيسبوك / تيك توك + yt-dlp) | ⏳ |

## التشغيل على الماك

```bash
npm install
npm run dev          # يفتح نسخة الويب في المتصفح
npm run build:preview  # ملف HTML واحد للتجربة
```

## ملاحظات

- نسخة الويب بتعرض ملفات أمثلة، لأن المتصفح مش بيقدر يقرا ملفات الموبايل. الملفات الحقيقية والتحميل والبصمة بيشتغلوا في الـ APK بس.
- مفتاح التوقيع `android/app/hammel.jks` متخزن في المستودع عشان كل نسخة تتسطّب كتحديث فوق اللي قبلها.
